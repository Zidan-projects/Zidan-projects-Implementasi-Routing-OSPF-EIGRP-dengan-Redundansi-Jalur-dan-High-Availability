# Implementasi-Routing-OSPF-EIGRP-dengan-Redundansi-Jalur-dan-High-Availability
Project akhir semester 1 kelas 11-TJKT. Project mata pelajaran Cisco

Tujuan utama dari proyek Cisco "Implementasi Routing OSPF-EIGRP dengan Redundansi Jalur dan High Availability" adalah membangun arsitektur jaringan skala menengah hingga besar (enterprise) yang tangguh, cepat beradaptasi saat terjadi gangguan, dan mampu meminimalkan waktu henti (downtime).

Berikut adalah rincian tujuan teknis yang ingin dicapai dalam proyek ini:1. Interoperabilitas Antar-Protokol (Route Redistribution)Menyatukan Dua Sistem Routing: Mengintegrasikan jaringan yang menggunakan protokol standar terbuka (OSPF) dengan jaringan yang menggunakan protokol khusus Cisco (EIGRP).Pertukaran Informasi Rute: Memastikan seluruh perangkat di kedua domain routing dapat saling berkomunikasi secara penuh melalui proses route redistribution yang terkonfigurasi dengan aman (mencegah routing loop).2. Redundansi Jalur (Path Redundancy)Menghilangkan Single Point of Failure: Menyediakan lebih dari satu jalur fisik maupun logis antar-router atau antar-gedung/cabang sehingga lalu lintas data tidak bergantung pada satu kabel atau satu perangkat saja.Optimalisasi Jalur dan Load Balancing: Memanfaatkan jalur cadangan tidak hanya sebagai backup, tetapi juga untuk membagi beban lalu lintas (equal-cost maupun unequal-cost load balancing pada EIGRP) agar penggunaan bandwidth lebih efisien.3. Ketersediaan Tinggi (High Availability / HA)Failover Otomatis (Fast Convergence): Memastikan jaringan dapat mendeteksi kegagalan tautan (link failure) atau perangkat mati secara otomatis dan mengalihkan lalu lintas ke jalur cadangan dalam hitungan detik tanpa intervensi manual.Redundansi Gateway (FHRP): Biasanya proyek ini juga mencakup implementasi FHRP agar perangkat klien (end-user) tetap terhubung ke jaringan meskipun router default gateway utamanya mengalami kerusakan.4. Skalabilitas dan Manajemen JaringanSegmentasi Terstruktur: Menerapkan desain hierarkis (seperti penggunaan Multi-Area OSPF) untuk membatasi penyebaran pembaruan routing (LSA flooding), menghemat penggunaan CPU/memori router, dan mempermudah pengembangan jaringan di masa depan.
